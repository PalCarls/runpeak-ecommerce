# RunPeak eCommerce

Proyecto académico de Ingeniería de Software para demostrar la integración de Scrum, DevOps y DevSecOps mediante el desarrollo de un e-commerce deportivo.

## Stack previsto

- Frontend: React + Vite + TypeScript
- Backend: Express + TypeScript
- ORM: TypeORM
- Base de datos: PostgreSQL
- CI/CD: GitHub Actions
- Seguridad: CodeQL y Dependabot

## Flujo de trabajo

Issue → Rama → Pull Request → CI → Revisión → Merge
